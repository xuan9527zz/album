# 字体文件与来源

这些 WOFF2 文件由原项目字体转换压缩，保留原字库及字体内部名称；未按演示文案裁成子集。CSS 中的 `Zine*` 是网页字体家族别名。交付、发布时保留本文件及 `licenses/` 中的对应许可。

| ------------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------- | ------------------ |
| `smiley.woff2`                  | 得意黑 Smiley Sans                 | [atelierAnchor / smiley-sans](https://github.com/atelier-anchor/smiley-sans)             | `Smiley-OFL.txt`   |
| `huiwen.woff2`                  | 汇文明朝体（符号修正版）           | [汇文明朝体符号修正版](https://github.com/bosswnx/huiwenmincho-improved)                 | `Huiwen-CC0.txt`   |
| `han-serif.woff2`               | 思源宋体 SC Regular                | [Adobe / Source Han Serif](https://github.com/adobe-fonts/source-han-serif)              | `HanSerif-OFL.txt` |
| `han-sans.woff2`                | 思源黑体 SC Regular                | [Adobe / Source Han Sans](https://github.com/adobe-fonts/source-han-sans)                | `HanSans-OFL.txt`  |
| `inter-400/500/600.woff2`       | Inter 400 / 500 / 600              | [Google Fonts / Inter](https://github.com/google/fonts/tree/main/ofl/inter)              | `Inter-OFL.txt`    |

得意黑、思源系列及上述英文字体随各自 SIL OFL 1.1 文本提供；汇文明朝体随 CC0 文本提供。本包不含用户推荐的商业字体文件。若日后换成方正 FW 筑紫古典、Helvetica、Futura、Frutiger 或商业 Univers / Bodoni 版本，应由网站持有相应 Webfont 授权，并重新检查换行、纵排与字号。
