# 完整跨页和照片取景（2026-10-15）

手机和电脑都以一个完整跨页切换，左右页 1+2、3+4、5+6 分别组成一次观看画面。页码表示跨页数量，手机不再把三跨页拆成六次切换，编辑器也预览完整跨页。调整窗口尺寸时不会重置观看位置。横向动画、BGM 及作者设置的自动翻页间隔仍保留。

共享相册增加“制作影集”入口，直接进入共享照片选择，卡片显示上传成员。可使用别的家庭成员仍在共享的照片；现有后端权限本来就支持这种创建行为。本次用其他成员的合成照片验证选择、保存、重编辑和家庭读取；照片撤回共享或进入最近删除后，引用停止可见，不将后面的照片挪入空位置。仅影集主人能编辑。公开链接继续只允许作者自己的照片，未将家庭共享权限改成互联网公开权限。

工作台照片框支持双指缩放、单指移动，电脑支持拖动及缩放滑块，取景可重置。缩放 1–5 倍，移动受到边缘约束，避免露出照片以外的空白。取景存于每个跨页的 `photo_crops`，不改动原件。替换照片或排版会重置相应取景；网页观看和 PDF 采用同一个取景几何计算。
