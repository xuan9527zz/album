# 完整跨页和照片取景（2026-10-15）

手机和电脑都以一个完整跨页切换，左右页 1+2、3+4、5+6 分别组成一次观看画面。页码表示跨页数量，手机不再把三跨页拆成六次切换，编辑器也预览完整跨页。调整窗口尺寸时不会重置观看位置。横向动画、BGM 及作者设置的自动翻页间隔仍保留。

共享相册增加“制作影集”入口，直接进入共享照片选择，卡片显示上传成员。可使用别的家庭成员仍在共享的照片；现有后端权限本来就支持这种创建行为。本次用其他成员的合成照片验证选择、保存、重编辑和家庭读取。用户随后明确允许这些照片生成公开链接，第十二次迁移 `202610150003_shared_story_links.sql` 已成功执行：公开链接只读取仍共享、照片主人仍启用的预览；撤回共享或最近删除后隐藏对应照片，不向匿名读者提供原件。新链接仍须由影集主人主动创建，可撤销；未为正式家庭影集创建新链接。

工作台照片框支持双指缩放、单指移动，电脑支持拖动及缩放滑块，取景可重置。缩放 1–5 倍，移动受到边缘约束，避免露出照片以外的空白。取景存于每个跨页的 `photo_crops`，不改动原件。替换照片或排版会重置相应取景；网页观看和 PDF 采用同一个取景几何计算。

第十一次迁移 `202610150002_story_photo_crops.sql` 已在正式项目执行成功。新增 `album_v11_action`，仅 service_role 可执行，委托 v10 的所有权、共享、照片、BGM 和时间间隔校验。照片取景只接受槽位长度匹配的有限数字及三个固定键。Worker `9c3281f4-9cac-43d6-a1c2-f09a4dcd79f4` 已部署。
