# 新版影集说明（2026-10-14）

## 使用方式

进入导航里的“影集”，点击“制作影集”，依次完成照片、设计和音乐。只提供压缩包里的三套模板：途中、余日、潮汐，共 12 种跨页。每套可选择版式、分配照片、调整跨页顺序和输入短句；标题、时间和地点仍读取照片资料。背景输入支持 `#F5F3ED`、`F5F3ED`、`#FFF`，保存时统一为六位颜色。旧影集适配到新模板，保留照片引用；旧模板不再供新建或保存使用。

保存后进入观看，电脑显示跨页、手机逐页横向切换，可用滑动、按钮、键盘和按页跳转；可选平移、淡入、轻推动画。背景变化会调整基础文字的明暗；模板强调色保留。开启完整文字阅读时暂停自动放映。

作者在观看页点击“导出”：

- 链接观看：主动生成后任何拿到链接的人可看，页面明确提示会公开照片及标题、时间、地点。只支持本人上传的照片；包含其他家庭成员照片时拒绝生成。链接可关闭或重新生成，重新生成会使旧链接失效。服务端只存 256 位随机令牌的 SHA256；重新打开导出窗口不能恢复原令牌。
- PDF：每个跨页保存为一页，顺序、裁切、字体和背景色保留。使用预览图生成，不改动原件；目前为图片型 PDF，文字不可选取。音乐和动画仅在网页中提供。

## 音乐基础版

粘贴网易云普通、移动或 hash 形式的完整单曲链接，或 QQ 含数字 `songid` 的完整单曲链接。短链、分享文案、歌单、MV、`songmid` 与未验证的 `songDetail` 数字映射均不接受。服务端保存平台、数字 ID、可选标题/歌手和启用状态，规范歌曲页与 iframe 地址由固定白名单重新构造；不接受用户的 iframe HTML 或任意音频地址。

读者主动点击“开启音乐”后才挂载一个官方 iframe，还需在官方控件中点击播放。翻页和收起保留同一节点；关闭、退出、切换曲目、权限失效和 pagehide 会释放它。慢加载和平台问题不阻止翻页；始终提供平台打开、重新载入和关闭。站点不代理、下载、持久缓存音乐，不展示未经确认的播放状态。

已尝试手动点击，未确认音频持续播放或时间推进；不能据此声称播放通过。真实 iPhone Safari、桌面 Safari、Android、会员/不可用曲目降级和中国大陆无 VPN 网络的音频播放尚未验证。控件由平台提供，试听、会员、地区、版权和网络限制继续适用。

## PWA 预存

安装先保存必要页面外壳，再以两个并发后台预存网站全部构建静态资源，包括完整字体、影集、PDF、HEIC 与 Web Worker 代码，约 32 MiB。预存下载不会使这些模块提前执行；首页仍按需加载功能。可在“我的”查看状态和继续预存，未完成项下次打开继续。新版复用未变更的带哈希文件，只下载新增资源；页面外壳和程序优先读缓存。

照片、认证、业务 API、公开影集数据与第三方音乐不写入 Service Worker 持久缓存。照片沿用 64 MiB 页面内存缓存；关闭页面或退出登录释放。浏览器或系统可能清理网站缓存，用户清除网站数据后也会重新下载；不能保证缓存永久保留。尚未测量真实 iPhone 首次下载与重复启动耗时。
