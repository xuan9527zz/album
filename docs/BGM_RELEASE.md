# 影集文件配乐（2026-10-15）

后续版本已支持上传 MP3、72 小时过期及循环放映，并移除观看页文字展开区。当前行为和部署记录见 [上传配乐与观看适配](TEMPORARY_MUSIC_RELEASE.md)；下文为首次文件配乐版本记录。

工作台“背景音乐”可选择已公开上传的《Whenever》，也可以在“粘贴歌曲链接”中填写该 MP3 的完整直链。选择后默认启用，保存到影集；启用的配乐随共享影集和公开链接读取。当前文件配乐目录只注册这首歌，不接受任意音频服务器或签名链接。旧平台曲目配置保留，仍由官方控件独立播放。

“编排版面”中的自动翻页间隔支持 2–60 秒的整数，默认 6 秒。保存在 `zine_config.slide_seconds` 中，旧影集缺少此字段时继续使用 6 秒。PDF 排版保持原样。

观看页底部内嵌曲名和静音按钮，移除浮动音乐卡片、下载百分比、时间进度条和说明段落。点击“播放影集”在该点击内直接调用原生音频播放；音乐开始后才计时自动翻页。暂停、打开文字阅读、按页跳转或切到后台会同时暂停音乐与翻页。最后一页展示完整间隔后停止，重播从第一页和音乐开头开始。音乐暂时不可用时可静音继续，超时或出错可重试。翻页时保留同一个音频元素，不重新设置音频来源。

程序、模板、字体和工具沿用 PWA 预装。MP3 不加入 Service Worker 永久缓存；原生播放器由浏览器按需缓冲，不能把部分可播放缓冲当作整文件下载 100%。

迁移 `202610150001_story_playback.sql` 增加 file 配乐约束，重算已有的生成音乐 URL 字段，并增加受控 `album_v10_action`；已有平台 URL 的值保持一致。新 RPC 委托现有权限、照片和公开链接校验，服务端白名单与输入验证限制曲目及秒数，不修改私人照片或自动共享影集。Worker 改用该 RPC，Supabase 网关路由不变。

本地已验证十次迁移、49 项数据库/API测试、类型检查、Worker dry-run、PWA 缓存与升级/恢复，以及三浏览器的原生播放、同步暂停、秒数保存、公开链接读取、完整最后一页停留、错误/超时/重试。图片均为合成素材。真实 iPhone 之前已经确认原生 MP3 可以发声；新的“一键音乐与放映”仍需设备复测。

正式功能从 `63752bc` 经 [Pages #30](https://github.com/xuan9527zz/album/actions/runs/38622320070) 发布成功；[Checks #53](https://github.com/xuan9527zz/album/actions/runs/38622272307) 的 49/49 数据库/API、60/60 浏览器以及 PWA 预存、升级和恢复检查全部通过。正式试播页实际更新后，单击播放使音频时间前进并按默认 6 秒进入第二页；暂停停止音频。390px 布局无横向溢出，音乐位于底部。正式工作台可选 Whenever、默认启用，翻页间隔显示 6 秒；只检查未保存的草稿，没有改动正式影集或新建公开链接。
