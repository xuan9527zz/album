# MP3 文件配乐试验

当前是本机试播原型，不是正式影集的音乐配置格式变更。正式网易云/QQ 音乐设置、数据库及公开影集均保持原样；真实 iPhone 和 GitHub 网络传输还没有验收。

2026-10-15：用户样本 9,970,460 bytes、320 kb/s、约 4:09。在桌面内置浏览器显示实际 45%（约 4.5 / 10.0 MB）后达到 100%，点击播放并翻到第二页，时间继续至 0:16。原件未改动、未复制入仓库或上传到 GitHub，试播页面使用合成照片。专项检查 7 项通过、2 项因 Windows WebKit 的 Blob 音频限制跳过；类型检查与生产构建通过。生产构建不会开启试播入口。

`FileAudioPlayer` 完整下载音频，按已接收字节显示进度。收到全部字节后仍等待原生播放器确认可播放，才显示 100%；未知总长度显示不确定进度。点击播放，暂停、拖动进度、循环播放、收起面板及静音继续浏览均可操作。播放器不随翻页重新创建，已准备的文件在当前页面中复用。关闭配乐或离开影集会取消请求、停止播放并释放临时地址。

下载采用 45 秒无数据超时、10 分钟总上限和 40 MiB 文件上限；网络失败或格式错误不会显示成功，用户可重试或静音观看。音频不加入 PWA 的 31 项永久预装清单。

开发服务仅绑定 `127.0.0.1`，指定本机样本：

```powershell
$env:ALBUM_MUSIC_TRIAL_FILE='C:\path\sample.mp3'
npm run dev:local
```

选择示例账号并创建一个包含至少两张示例照片的影集，在它的 URL 中加入 `?musicTrial=1`，例如 `http://127.0.0.1:5173/?musicTrial=1#/stories/影集ID`。指定文件通过本机开发代理按 64 KiB / 80 ms 的节奏发送，用于观察真实百分比；没有提供文件时使用仓库中的合成测试音频。此入口仅在开发演示中生效，生产构建无法开启。

`tests/fixtures/audio-tone.mp3` 为独立生成的 8 秒、330 Hz、低音量测试音。生成命令：

```text
ffmpeg -f lavfi -i sine=frequency=330:duration=8 -af volume=0.05 -codec:a libmp3lame -b:a 96k -ar 44100 tests/fixtures/audio-tone.mp3
```

桌面/手机尺寸 Chrome 验证完整下载、点击播放、翻页维持同一个音频元素、断网继续播放、取消和重试。Windows 自带的 Playwright WebKit 在独立基线检查中能播放同一 MP3 的 HTTP URL，但拒绝其 Blob URL；其两项实际播放测试明确跳过，错误和静音继续的测试仍执行。该环境限制不能代替真实 Safari/iPhone 验收。

后续接入正式公开影集前，需要验证真实 iPhone 的缓存音频播放、选择实际托管位置、为音乐资源增加受控配置及上传/删除机制，并决定音乐文件的公开访问范围。当前不将用户提供的歌曲复制到 Git 或公开静态目录。
